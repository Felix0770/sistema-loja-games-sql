# Sistema de Loja de Games - MySQL

Projeto acadêmico desenvolvido na disciplina de Modelagem de Dados, com o objetivo de criar um banco de dados para gerenciamento de uma loja de games.

## Sobre o projeto

O banco de dados permite o gerenciamento de clientes, funcionários, jogos, plataformas, categorias, vendas, itens de venda e pagamentos.

O projeto foi desenvolvido utilizando MySQL e inclui criação de tabelas, relacionamentos, inserção de dados, consultas SQL e triggers para validação e atualização do estoque.

## Tecnologias

- MySQL
- MySQL Workbench

## Funcionalidades

- Cadastro de clientes e funcionários.
- Cadastro de jogos, categorias e plataformas.
- Registro de vendas e pagamentos.
- Controle de estoque.
- Consultas SQL básicas, intermediárias e avançadas.
- Triggers para validação de quantidade e atualização do estoque.

## Objetivo

Aplicar na prática os conceitos de modelagem de dados, relacionamentos entre tabelas e linguagem SQL, desenvolvidos durante os estudos de Banco de Dados.
